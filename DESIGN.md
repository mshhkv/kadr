# Kadr — видеодвижок для нейросети

Рабочее название. Агент описывает фильм текстовым документом. Kadr собирает из него видео, в котором дрожь невозможна по построению, и сам сообщает агенту, что в фильме не так.

Это не монтажка для человека: окон нет. Это «After Effects без интерфейса» с глазами для агента.

## Зачем

| Боль | Ответ Kadr |
|---|---|
| Дрожь текста и фото, баги в движении | Рендер с гарантиями (см. «Рендер») и проверка движения на каждом прогоне |
| Шаблоны и лейауты зажимают | Модель AE: композиции, слои, 2.5D-камера, ключевые кадры с кривыми |
| Переозвучка ломает тайминги | Время задаётся словами озвучки, а не секундами |
| Брак ищет человек или сабагенты по скриншотам | `kadr check` пишет отчёт текстом с местом: время, слово, слой |
| Chrome — самая медленная часть рендера | Нативный рендер, кадры параллельно, без браузера |

Чем Kadr **не** является: генератором материала (картинки, видео, голос приходят извне), сценаристом (документ пишет агент), монтажкой с интерфейсом (для ручной доводки — экспорт).

## Решения, подтверждённые замерами (27.10.2026)

Стенд: наезд на текст (рус+греч) и пролёт камеры, 125 кадров, эталон 8× с box-уменьшением.

- **Текст — контуры с дробной позицией, растеризация точной площадью покрытия в 1×** (FreeType, позиция 1/64 px). Уход строки с траектории 0,05 px против 0,29–0,31 у Chrome; рывковость равна эталону. Суперсэмплинг не нужен: 4× оказался хуже и в 25 раз медленнее.
- Кэш глифов с округлением позиции (Chrome, Skia `drawString`) дрожит: строка прыгает по вертикали до ±0,5 px. `will-change` не помогает.
- **Картинки — Ланцош со сглаживанием** (при уменьшении ядро расширяется на 1/s). Минимум мерцания детали во всех сценах при 23 мс на кадр 1080p. Chrome масштабирует `<img>` билинейно без мип-карт и мерцает в 3,6–5,5 раза сильнее эталона.

## Документ фильма

YAML (или JSON). Один файл — один фильм.

```yaml
film:
  size: [1920, 1080]
  fps: 25
  duration: 6
  background: "#0b1530"
  words: voice.words.json          # Whisper verbose_json или список {word, start, end}
  audio:
    - {src: voice.mp3, at: 0}

layers:                            # снизу вверх; 3D-слои сортируются по глубине
  - id: cam
    type: camera
    zoom: 1000                     # слой на глубине z=zoom от камеры виден в масштабе 1
    position: {0: [0, 0, 0], 6: [0, 0, 300], ease: inOut}

  - id: map
    type: image
    src: map.png
    z: 1800                        # есть z → слой в 3D-пространстве камеры
    size: cover                    # cover | contain | [w, h] | native

  - id: title
    type: text
    text: "Σιγκαπούρη, 1942"
    font: Arial
    size: 64
    color: "#ff9628"
    align: center
    z: 1500
    in: word:Сингапур              # появляется на слове
    opacity: {word:Сингапур: 0, word:Сингапур+0.4: 1}
```

### Кадры и стиль канала (главный способ писать фильм)

Агент пишет фильм не слоями, а **кадрами**: что на экране и до какого слова. Как выглядит кадр — бумага, тени, пружинка, плашки, сцена, — решает стиль канала (`film.style`), как шаблоны Essential Graphics в Premiere.

```yaml
film:
  style: mychannel                   # стиль канала: свой плагин (см. ниже)
  root: ~/films/harbor                # относительные пути к материалу — отсюда
  words: minute.words.json
  audio: [...]
shots:
  - omni: clips/s0322.mp4            # один ключ называет вид кадра и его материал
    to: word:Ямамото                 # кадр кончается здесь (или len: 4.2); начинается там, где кончился прошлый (или at:)
    stamp: {line1: ОСЕНЬ 1941, line2: "Токио, морской генштаб"}
  - id: genda
    print: graphics/public/arch/genda_portrait.jpg
    to: word:Капитану
    speaker: {name: Минору Гэнда, sub: "штабной лётчик, автор плана"}
    source: Imperial Japanese Navy (public domain)
  - chapter: {n: 4, title: Слух из Токио}
    len: 4.5
    tr: fadeblack
```

| Вид | Что | Свои свойства |
|---|---|---|
| `photo` | архивное фото на весь кадр, медленный наезд, подпись | `zoom: [от, до]`, `origin: [x %, y %]` |
| `print` | фото-«печать» с полями, наклоном и тенью; рядом со `speaker` уходит вправо | `zoom`, `tilt` |
| `doc` | документ на столе, камера едет к выделенной строке | `highlight: [x, y, w, h]` в % страницы, `highlight_at` (с), `zoom_to`, `tilt` |
| `video` | съёмка | `from`, `speed`, `crop`, `flip`, `grade`, `volume`, `loudness` |
| `omni` | сгенерированный клип | `from`, `fit` (auto / true / false — замедлить до стыка), `speed`, `until`, `delogo`, `ambience`, `flip` |
| `line` | реплика ведущего | `from`, `sound_len` |
| `chapter` | карточка главы | `{n, title, kicker}` |
| `title` | титул фильма (sw) | `{text, kicker}` |

У любого кадра: `id`, `label`, `source`, `stamp {line1, line2}`, `speaker {name, sub}`, `over`, `tr` — переход в этот кадр: `fade`/`dissolve`, `fadeblack`, `fadewhite`, `hblur` (оба кадра размываются по горизонтали сквозь склейку), `zoomin` (прошлый кадр наезжает и растворяется), `smoothleft`/`smoothright`/`smoothup`/`smoothdown` (шторка); или `[вид, секунды]`. Переходы, двигающие кадр целиком, Kadr делает, сам заворачивая кадр во вложенную композицию. Обычные `layers:` ложатся поверх всех кадров — для всего, чего нет в стиле. Кадр может выходить за пределы фильма: Kadr сам обрежет его и сдвинет точку входа в съёмку.

`check` говорит языком кадров («кадр genda (print) → подпись в плашке») и ловит оборванный запятой YAML («похоже, запятая оборвала текст: возьмите значение в кавычки»).

Минута документального фильма: 151 строка кадрами против 7787 строк слоями, кадры совпадают с послойной версией (62 из 63 бит в бит, в одном — сдвиг анимации на 1 мс).

### Расширение без правки движка

Ядро Kadr не меняется, когда нужен новый элемент. Пять уровней, от простого к сильному; каждый — файл в папке плагинов или строки в документе:

1. **Слои напрямую** — всё, чего нет в стиле: фигуры, текст, градиенты, маски, формулы.
2. **Шаблон в YAML** — новый вид кадра из слоёв с параметрами, без кода. В документе (`templates:`) или файлом `.yaml` в папке плагинов. `{name}` подставляет параметр, `=len-0.5` — формула; время в шаблоне — от начала кадра.
3. **Элемент и стиль на Python** — `@element('bignumber', style='mychannel', params={...})` добавляет вид кадра (для одного стиля или для всех), `@style('mychannel')` — целый стиль канала. Стилю доступны помощники (появление, пружина, наезд, сцена), сам фильм (`st.film`: пути, размер, слова) и соседние кадры (`st.prev`, `st.next`); стиль сам объявляет поля своих штампов и плашек (`fields`).
4. **Новый тип слоя** — `@layer_type('radar', params={...})`: плагин рисует только свою рамку (Skia-холст в своих единицах или массив пикселей); положение, масштаб, поворот, прозрачность, размытие, тени, маски, эффекты и проверка — от движка. Для схем, которые меняются каждый кадр (циферблаты, счётчики, графики), вместо тысяч слоёв.
5. **Новый эффект на шейдере** — файл `.wgsl` с одной функцией `effect` (рядом с фильмом: `effects: [{type: shader, src: fx/x.wgsl, …}]`, или текстом в `code:`; встроенные — `kadr/shaders`, см. `kadr catalog effects` и AE.md «M1»). Считается на видеокарте, параметры анимируются, ошибка в коде приходит текстом в `kadr check`.
6. **Новый эффект на Python** — `@effect('scanlines', params={...})`: функция получает картинку слоя (цвет и альфа) и возвращает новую; в документе — `effects: [{type: scanlines, gap: 4}]` у любого слоя, параметры анимируются. Встроенные эффекты (`kadr/effects.py`: glow, fill, tint, levels, invert) написаны так же.

Папки плагинов: `kadr/styles` (встроенные), `~/.kadr/plugins`, `$KADR_PLUGINS`, `film.plugins` (относительно документа). Примеры (в рабочих фильмах автора): стрелка с подписью — элемент, нижняя плашка — шаблон, радар и строки развёртки — тип слоя и эффект (`v2.yaml`, `plugins/radar.py`). `kadr catalog <стиль>` перечисляет всё, что подключено.

### Свобода слоёв

- `shape` — фигуры и кривые: `rect` (со скруглением), `ellipse`, `line`/`polyline`/`polygon` по точкам, `path` (SVG: M L H V C Q Z); заливка, обводка (`cap`, `join`, `dash`), `trim: [начало, конец]` — рисование по ходу, `arrow: end|start|both`; поворот и масштаб вокруг `anchor`. Рисует Skia со сглаживанием при 2× разрешении.
- `blur` бывает направленным: `[по x, по y]`.
- `shadow` — одна тень или список (как в CSS); `blur`, `offset`, `opacity`, `spread` анимируются; `outside: true` — тень только снаружи, как CSS box-shadow; `spread` — px, как в CSS box-shadow (тень шире предмета, углы скругляются; < 0 — уже); `space: layer` — сдвиг, размытие и spread в пикселях слоя: поворачиваются, сплющиваются и отражаются вместе с ним, у 3D-слоя сдвиг идёт через перспективу (дальний край тени уходит меньше ближнего). `mask` анимируется.
- `blur_space: layer` — размытие слоя в его собственных пикселях: у сплющенного или скошенного слоя оно эллипсом, как CSS `filter: blur` на элементе с `transform`. Эффект `glow` — то же через `space: layer`.
- `filter` — фильтр картинки слоя, как CSS filter: `brightness`, `contrast`, `saturation`, `sepia`, `gamma`, анимируемые.
- `gradient` с `size` — градиент в своей рамке (центр — `position`), а не на весь кадр. В `grade` есть `balance` (цветовой баланс теней, середин и светов).
- SVG-пути в `shape` понимают M L H V C Q A Z.
- `matte: {src: id, mode: alpha | luma | alpha_inverted | luma_inverted}` — трек-маска, как в AE: другой слой (текст, фигура, градиент, что угодно) решает, где этот слой виден; сам слой-маска не рисуется. Съёмка сквозь буквы, градиент по повёрнутой бумаге, вытеснение по фигуре.
- `effects: [...]` — цепочка эффектов у любого слоя (см. «Расширение»).
- Формулы видят другие слои и общие переменные (AE.md «M2 и M4»): `=layer('id').rotation`, `.position`, `.x`, `.world`, `.at(t - 0.2)`; `film.vars: {имя: значение | ключи}` и `var('имя')`.
- Объём из фото: `kadr depth фото.jpg` кладёт рядом `фото.depth.png` (белое — близко); слой с ней (`visible: false`, та же рамка) — `map` эффекта `parallax` (`shift` анимируется, `focus` — глубина, что стоит на месте). Рисунок на плоской вещи модель принимает за рельеф: `--smooth "x0,y0,x1,y1"` (или многоугольник, можно несколько) делает глубину области гладкой — область называет нейросеть по координатам фото, заходить за край вещи можно. См. `kadr/depth.py`, `kadr/_depth_smooth.py`.
- Время: `time:` у `video` и `comp` — Time Remap (ключи / формула; `frame_blend` у видео); у любого слоя `echo: {count, step, decay}` — шлейф, `posterize: fps` — движение шагами.
- Контур фигуры — данные (`kadr/paths.py`, AE.md «M3»): `d` / `points` ключами `{время: фигура}` морфят; `text:` у фигуры — контуры букв (`font`, `weight`, `font_size`, `tracking`), которые можно обвести и прорисовать `trim`, пустить по кривой (`along`, `along_offset`); `paths: [{…, at, op: union|subtract|intersect|xor}]` — слияние контуров; `offset` — расширить / сжать контур на px; `repeat: {count, offset, rotation, scale, anchor, opacity: [первая, последняя]}` — повторитель. Всё числовое анимируется.
- Маска-кривая: `mask: {d | shape + size | paths…, feather: px, invert, space: frame | layer}` — любой такой контур (и его морфинг) как маска слоя с мягким краем; `space: layer` — в пикселях слоя, едет и вращается с ним.
- Заливка и обводка фигур — цвет, `#rrggbbaa` или градиент `{gradient: linear | radial, stops, from/to | center/radius}` в координатах фигуры; `dash_offset` анимируется («бегущие муравьи»); `radius` прямоугольника (скругление углов) анимируется — полоса плавно становится «таблеткой».
- Градиенты (слой `gradient` и заливки) смешивают точки в premultiplied, как CSS: красный → `transparent` тает красным, а не через чёрный; `interpolate: straight` — по-старому (цвет и прозрачность отдельно). Цвет `transparent` понимается.
- `font` — один шрифт или список: символ, которого нет в первом, берётся из следующего. `weight` — насыщенность вариативного шрифта. `features` — OpenType-функции: `[tnum]` табличные цифры (счётчики не «прыгают»), `[lnum]`/`[onum]` выровненные/старостильные, `[smcp]` капитель, `{liga: false}`. Набор — HarfBuzz, как в Chrome, с кернингом.
- Размытие, свечение и тени видят то, что чуть за краем кадра: у края нет «проседания».
- `comp` — вложенная композиция (прекомп): свои слои со своим временем (`time`, `speed`), своим размером; сдвигается, масштабируется, поворачивается, размывается и отбрасывает тень как одно целое. Можно вложить файл (`src`).
- Формулы в любом анимируемом свойстве: `=960 + 30*sin(t)`, `=[1700 + wiggle(0.3, 6, 1), 200]`, `=max(0, 1 - lt/2)`; `t` — время фильма, `lt` — время от начала слоя, `wiggle(частота, размах, зерно)` — плавное случайное покачивание.
- Звук в формулах (`kadr/sound.py`): `amp(src)` — громкость сейчас, `band(lo, hi, src)` — громкость полосы частот; 0…1 от самого громкого места этого звука, `fall` — за сколько секунд спадает после удара. `scale: =1 + 0.3 * band(40, 120)` — прыжок на бочку. Значение — функция файла и времени, без памяти о прошлых кадрах.
- Кукла (`film.poses`, `pose()`): позы задаются как актёру — `[когда, за сколько секунд, {что: чему равно}]`; каждое значение плавно идёт от того, чем было, к новому. У 3D-сцены из файла именованные узлы двигаются формулами (`nodes: {head: {rotation: …}}`), камера и её склейки — в документе (`camera`, `cuts`); `rig: файл.yaml` — «нитки», записанные один раз. Персонажа руками не собирают: `shape: figure` (`kadr/figure.py`) — блочная фигурка из нескольких слов (рост, цвета, причёска, шапка, пропорции, сидит или стоит) приносит и тела, и свои «нитки»: `figure.build` разворачивает запись в обычные узлы с именами `имя.часть`, `figure.wire` при чтении фильма заводит позу (если её нет), общие значения и формулы частей; поза покоя вычисляется теми же формулами, что ведут фигурку в фильме, поэтому сцена без фильма и первый кадр фильма совпадают. Образец: четверо разных фигурок и фильм с ними — `examples/figures/`.
- Съёмка (`kadr/track.py`): `kadr track клип --name … --at … --region …` ведёт предмет по клипу (точка, место + размер + поворот, плоскость), в документе — `track("видео-слой", "имя").position / .corners / .scale / .rotation / .lost`; `kadr stabilize клип` + `stabilize: true` у видео-слоя убирает тряску (`lock: true` — штатив). Результаты лежат рядом с клипом (`клип.track.json`, `клип.stab.json`), рендер их только читает.
- Вырезание (`kadr/matte.py`): `kadr matte клип | фото` — мат людей (или `--what subject` — главного предмета) встроенными средствами macOS, `клип.matte.mp4` рядом; в документе `cutout: true` у слоя `video` / `image` (под капотом скрытый слой-мат в том же месте и времени).
- Кадр `over: true` ложится поверх предыдущего (плашка, стрелка, титр), не сдвигая последовательность.

### Время

Везде, где нужно время, годится:
- число — секунды (`3.5`);
- `word:Сингапур` — начало первого вхождения слова (без учёта регистра и пунктуации);
- `word:Сингапур#2` — второе вхождение, `word:Сингапур.end` — конец слова;
- смещение: `word:Сингапур+0.3`, `word:Сингапур-0.2`.

Переозвучили — пересчитали тайминги — всё встало на новые места без правки документа.

### Свойства

Значение свойства — константа или ключевые кадры `{время: значение, ..., ease: ...}`.
`ease`: `linear`, `hold`, `in`/`out`/`inOut` (мягкие, по умолчанию `inOut`), `inQuad`/`outQuad`/`inOutQuad`, `inCubic`/`outCubic`/`inOutCubic` (как в Remotion и AE) или `[x1, y1, x2, y2]` — своя кривая Безье, то же, что «ручки скорости» ключа в AE.

У любого слоя есть `blend`: все режимы CSS (`normal`, `multiply`, `screen`, `overlay`, `soft-light`, `hard-light`, `darken`, `lighten`, `color-dodge`, `color-burn`, `difference`, `exclusion`, `hue`, `saturation`, `color`, `luminosity`), `add`, `subtract` и трафареты AE `stencil-alpha|luma`, `silhouette-alpha|luma` (всё нарисованное до слоя в его группе остаётся только там, где слой есть / где его нет); `visible: false` — не рисовать сам слой (карта, мат, родитель); `rotation` (градусы, по часовой); `blur` (px, как CSS blur); `shadow` (`blur`, `offset`, `opacity`, `color` — тень любого слоя: бумаги, плашки, текста); `mask: [x0, y0, x1, y1]` — прямоугольная маска в пикселях кадра.

У текста есть `stroke: {width}` — контур вместо заливки. У съёмки: `flip`, `until` (кадр исходника, на котором дубль обрезан, дальше стоп-кадр), `delogo: [x, y, w, h]` (закрасить значок интерполяцией краёв), `loudness`/`max_gain` (громкость звука съёмки в LUFS), `sound_to` (где у реплики кончается звук). `gradient.center` анимируется; слой `dust` — летящие пылинки.

Общие свойства слоя: `position` (центр в пикселях кадра; у 3D-слоёв — мировые координаты от центра), `z`, `scale`, `opacity`, `in`, `out`.

### Типы слоёв (v0.1)

| Тип | Что |
|---|---|

Позиция текста — край выравнивания (`left`/`right`) или центр; подписи растут вверх от своей позиции (по умолчанию 90% высоты кадра).

### Переходы

У любого слоя: `fade_in`, `fade_out` (секунды) и `wipe_in`, `wipe_out` (`{dur, from: left|right|top|bottom}`). Растворение = следующий слой перекрывает предыдущий по времени и появляется с `fade_in`. Края вытеснения — точная площадь покрытия, без ступенек.

### Звук

`film.audio`: `src`, `at`, `from`, `to`, `role` (`voice`/`music`/`fx`), `loudness` (LUFS; по умолчанию голос −17, музыка −32), `volume` (дБ поверх), `duck` (дБ под голосом, у музыки по умолчанию −6), `fade_in`, `fade_out`. Приглушение идёт по словам озвучки (паузы короче 0,3 с не поднимают музыку, рампы 0,35 с). Итог — одна поправка до `film.loudness` (−16 LUFS) и лимитер на −1 dBFS.

Дальше: `shape` (кривые), `precomp`, маски и маты, `rotation`, переходы со сдвигом и маской по форме, слой из HTML или Lottie, растрированный один раз, слой из Blender.

## Рендер

- Каждый слой в каждом кадре — аффинное преобразование «содержимое → кадр» в float, без округлений.
- 2.5D: слой — плоскость на глубине `z`; масштаб `zoom / (z − z_камеры)`; сдвиг камеры по x/y даёт параллакс.
- Текст: FreeType, без хинтинга, каждый глиф трансформируется с дробной позицией и растеризуется точной площадью.
- Картинки: Ланцош со сглаживанием по дробному окну источника; края слоя — точная площадь покрытия.
- Съёмка читается через ffmpeg кадр в кадр: кадр исходника для времени t = floor(t·fps); блок читается вперёд без повторных перемоток.
- Смешивание во float32. Фильм режется на блоки по 50 кадров; каждый процесс рендерит и кодирует свой блок в H.264, блоки склеиваются без перекодирования, звук подмешивается в конце.
- Тени текста — гаусс с дробным сдвигом, поэтому при движении они тоже не шагают. Неподвижный текст (тот же масштаб и та же дробная позиция) растрируется один раз на блок.
- **Кодирование без B-кадров** (`-bf 0`, по умолчанию `crf 18`). У x264 качество I/P/B-кадров разное, и мелкая деталь «пульсирует» в их ритме: на архивных фото кодек давал мерцание в 10–30 раз выше рендера. Без B-кадров при том же потоке мерцание меньше в 4–7 раз. Выравнивание `ipratio`/`pbratio` не помогает.
- `Renderer(film, k, view)` рендерит окно кадра — для эталонов 4–8× без полного кадра в памяти.
- **Компоновщик как в AE.** Каждый слой рисуется в свой растр, затем один компоновщик накладывает его размытие, тень, маску, переход, прозрачность и режим наложения. Повёрнутые картинки: Lanczos до показа (неподвижная картинка готовится один раз с запасом 15 % и дальше только плавно масштабируется — иначе деталь «дышит»: замер 2,37 → 0,87 при эталоне 0,50), затем Skia поворачивает с кубическим фильтром и сглаженными краями. Текст поворачивает FreeType матрицей — с теми же дробными позициями.
- **Сильное размытие** (σ > 6) считается на уменьшенной в q раз копии и увеличивается обратно: ошибка ≤ 0,0024 от полного размаха, тень при сдвиге на 0,25 px смещается на 0,249 px, в 20–130 раз быстрее.
- **Дизеринг при переводе в 8 бит:** неподвижный треугольный шум ±1 уровень. Тёмный плавный градиент (свечение у края карточки) иначе распадается на несколько широких колец — у него всего 6 уровней яркости на сотни пикселей. Узор одинаков на всех кадрах, поэтому мерцания не добавляет.
- **Подложка:** нижние слои, которые ничем не меняются (нет анимации, перехода, съёмки), собираются один раз и переиспользуются; результат совпадает со свежим рендером бит в бит.
- Детерминизм: один и тот же документ даёт одни и те же кадры.

## Глаза (`kadr check`)

Отчёт текстом; у каждой находки есть время, слово (если есть озвучка) и слой.

v0.1:
- **документ**: неизвестные свойства (с подсказкой), слово-якорь не найдено (с похожими словами), нет файла;
- **кадр**: текст и подписи вне безопасной зоны, слой целиком за кадром, фон `cover` не закрывает кадр (дыра при сдвиге камеры), пересечение текстов;
- **движение**: рывок — скачок скорости, сосредоточенный в одном кадре (излом между ключами, старт или стоп без ease); быстрый, но плавный разгон рывком не считается; текст движется быстрее порога читаемости;
- **съёмка**: исходник кончается раньше слоя, `from` вне исходника, `volume` у немого исходника;
- **время**: `fade_in + fade_out` длиннее слоя, подпись читается быстрее 20 знаков/с;
- **гарантия рендера**: `kadr selftest` перерисовывает наезд на текст в 1× и 8× и меряет уход с траектории (порог 0,08 px).

Слои, нарисованные стилем канала, — его дизайн, однажды сверенный с роликами канала: им не ставят рывки, быструю скорость текста, безопасную зону, «за кадром» и перекрытия друг с другом. Судится то, что решает документ: какие кадры, до какого слова, длина дублей, свои слои агента, перекрытия между кадрами. `kadr check --strict` судит всё — для автора стиля.

Дальше: повторы кадров, подпись на лице, громкость, рассинхрон подписей с голосом.

Плюс глаза-картинки по запросу: `kadr frame --at word:Сингапур`, `kadr sheet` (лист раскадровки).

## Интерфейс

```
kadr render film.yaml -o film.mp4 [--from 2 --to 4] [--jobs 8]
kadr frame  film.yaml --at word:Сингапур -o f.png
kadr sheet  film.yaml -o sheet.png [--every 1]
kadr check  film.yaml
kadr srt    film.yaml -o film.srt
kadr selftest
```

Потом MCP-сервер с теми же командами.
